## 4. Brand/Season conventions are not universal rules
The Brand/Season set's conventions — the "Now Booking · 2026–2028" pill, brand-level rather than tour-level copy, homepage/Journeys destinations — belong to that set. The 14-Day set uses tour-specific years and tour pricing; the PMax set uses two asset groups with two different final URLs. Write each set's conventions under that set.

## 5. The "Brochure Collection Page" conversion
Describe it as a **URL-based custom conversion that counts visits to the brochure-collection page**. It does not independently verify a form submission; a visitor can reach the URL by other routes. Treat it as a proxy for brochure leads until submissions are tracked directly.

## 6. Font treatment — describe it accurately
The creatives use **Lora** (serif headlines and italic support lines) and **DM Sans** (eyebrows, pills, captions), with **DM Mono** in one helper; palette navy `#1a3a5c`, gold `#b8935a`, cream `#f6f1e6`, green `#2f6e4a`. The MOF v3 file declares **Montserrat** for its sans elements, but no supplied page loaded it, so every earlier render of MOF v3 fell back to DM Sans; the recovered package loads Montserrat so MOF v3 renders as its source declares and includes a side-by-side of both. The website uses a different system (Montserrat / Open Sans, `#153b67` / `#c8a56c`); the document must not describe that as the creative system.
