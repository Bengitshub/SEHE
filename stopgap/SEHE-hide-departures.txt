     SEHE — TEMPORARY: hide unverifiable departure data
     ───────────────────────────────────────────────────────────────────────
     WHY: departure dates, counts and "next departure" come from the
     Checkfront feed. Bookings have moved to the new booking system, so that
     feed can no longer be trusted. Kirsty asked (18 Sep 2026) for
     "Next departure" and "All departure dates" to be removed meanwhile.

     WHAT IT HIDES  (unverifiable specifics only)
       • "Next Departure" strips on every tour card
       • "All departure dates" month lists (Journeys + Brochure Collection)
       • departure COUNTS ("11 Departures", hero "Departures 11 · Nov 26 – Apr 27")
       • the homepage departure board / next-departure lines

     WHAT IT DELIBERATELY KEEPS VISIBLE
       • every SOLD OUT marker and sold-out note — removing these would make
         a sold-out tour look bookable, which is worse than the problem
       • prices, durations, routes, rail journeys, buttons, all other content

     WHERE TO PASTE: Duda → Site Settings → Head HTML (one paste, all pages).
     No page widget is touched. TO UNDO: delete this block and republish.

<style>
  /* Next-departure strips and the month-by-month date lists */
  .journey-card-next,
  .journey-card-departures,
  /* Availability pills — but NOT the sold-out variants (kept on purpose) */
  .journey-card-status:not(.journey-card-status-sold),
  .tour-card-status:not(.tour-card-status-sold),
  /* Homepage: departure board and next-departure lines (not sold-out lines) */
  .shx-depboard,
  .shx-depnext,
  .shx-jc-next:not(.shx-jc-next--sold)
  { display: none !important; }
</style>
<script>
  (function () {
    var PAIRS = [
      ['[data-sehe-dep-count]', '.sehe-hx-field'],
      ['[data-departure-value]', '.journey-card-fact'],
      ['[data-departure-value]', '.tour-card-fact']
    ];
    /* No less-than and no ampersand anywhere in this script: Duda escapes
       both inside head scripts, which is what silently broke the AdRoll
       pixel. forEach needs no comparison; nested ifs replace "and". */
    function keepIt(el) {
      return (el.textContent || '').toLowerCase().indexOf('sold') !== -1;
    }
    function hideOne(el, parentSelector) {
      if (keepIt(el)) { return; }
      var box = el.closest ? el.closest(parentSelector) : null;
      if (box) { if (keepIt(box)) { return; } }
      var target = box || el;
      target.style.setProperty('display', 'none', 'important');
    }
    function hideAll() {
      PAIRS.forEach(function (pair) {
        var found = document.querySelectorAll(pair[0]);
        Array.prototype.forEach.call(found, function (el) { hideOne(el, pair[1]); });
      });
    }
    hideAll();
    if (document.readyState === 'loading') {
      document.addEventListener('DOMContentLoaded', hideAll);
    }
    window.setTimeout(hideAll, 1200);
    window.setTimeout(hideAll, 4000);
  })();
</script>
